
# 📊 Python-Based Exploratory Data Analysis (EDA) Portfolio

A Python-based data analytics portfolio featuring five end-to-end Exploratory Data Analysis projects across restaurant, streaming, music, real estate, and retail domains.

## 📌 Project Overview

This portfolio demonstrates the use of Python for data cleaning, preprocessing, exploratory analysis, statistical analysis, and data visualization. Each project focuses on identifying patterns, understanding data distributions, and extracting meaningful insights from real-world datasets.

## 🚀 Projects Included

### 1. 🍽️ Zomato Restaurant Analysis
- Restaurant and cuisine analysis
- Data cleaning and missing-value handling
- Ratings and restaurant distribution analysis
- Visualizations and analytical insights

### 2. 🎬 Netflix Content Analysis
- Analysis of movies and TV shows
- Content type and category distributions
- Exploration of trends and dataset attributes
- Visualizations and key findings

### 3. 🎵 Spotify Music Analysis
- Exploration of tracks and audio features
- Analysis of feature distributions and relationships
- Music data visualization
- Identification of patterns in the dataset

### 4. 🏠 MagicBricks Property Analysis
- Analysis of Delhi real estate listings
- Data cleaning and duplicate removal
- Property price, area, BHK, and furnishing analysis
- Correlation and potential outlier analysis
- Ten visualizations and exported analytical reports

### 5. 🛒 BigBasket Product Analysis
- Product data exploration
- Analysis of product attributes and categories
- Data cleaning and visualization
- Summary of key findings

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook, VS Code
- **Data Storage:** CSV
- **Version Control:** Git and GitHub

## 📊 Key Features

- Data loading and initial inspection
- Data cleaning and preprocessing
- Missing-value and duplicate handling
- Descriptive statistical analysis
- Correlation and outlier analysis
- Univariate and multivariate analysis
- Data visualization using Matplotlib and Seaborn
- Exporting cleaned datasets, charts, and reports
- Data-driven insights across multiple domains

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Hemavathi0611/Python-EDA-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Python-EDA-Portfolio
```

### 3. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Open the notebooks

Open the project in VS Code or Jupyter Notebook, select the dataset you want to explore, and run its notebook cells sequentially.
